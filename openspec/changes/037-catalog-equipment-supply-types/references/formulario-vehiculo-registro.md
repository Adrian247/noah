# Formulario vehículo — enlace al tipo de equipo

> **Actualizado:** el entregable de 037 es un **formulario normalizado** para el tipo Vehículo, no solo reutilizar el slug demo premium.

Ver diseño: [`formulario-vehiculo-normalizado.md`](formulario-vehiculo-normalizado.md).

El formulario demo `revision-mayor-vehiculo-premium` en `NoahDemoSeeder` sirve como **referencia de patrones** (secciones, tipos de campo, catálogos de opciones), no como definición final.

Tras implementar:

- `equipment_types.vehiculo.default_form_definition_id` → formulario normalizado (`inspeccion-vehiculo-v1` o equivalente).
- Tipo de rutina demo enlazado a la versión publicada de ese formulario.
