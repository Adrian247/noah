# Dynamic Forms Engine — Phoenix

Los formularios son metadatos.

Cada **definición** tiene un **uso** fijo al crearla: rutina, equipo o insumo. Eso determina dónde puede enlazarse (tipo de rutina, tipo de equipo, tipo de insumo).

Cada formulario está compuesto por:

- Secciones
- Campos
- Validaciones
- Reglas
- Permisos
- Versiones

Los tipos de campo serán extensibles.

El motor deberá permitir crear nuevos formularios sin modificar código.

Diseño UX: captura web y renderer móvil comparten el mismo esquema publicado. Ver [design/mobile-field-app.md](../design/mobile-field-app.md).
