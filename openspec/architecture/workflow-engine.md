# Workflow Engine — Phoenix

Los procesos no deben codificarse por cliente.

Todo flujo será configurable.

Cada workflow podrá contener:

- Eventos
- Condiciones
- Aprobaciones
- Acciones
- Notificaciones
- Invocaciones IA
- Integraciones externas (futuro)
- Facturación
- Exportación

Cada workflow será versionable.

Los pasos concretos del flujo validación → IA → PDF → factura se modelan aquí, no en controladores de Maintenance.
