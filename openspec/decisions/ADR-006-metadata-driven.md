# ADR-006 — Metadata-driven (Phoenix)

## Título

Toda funcionalidad configurable mediante metadatos.

## Estado

Aceptada.

## Contexto

El sistema debe evolucionar sin recompilar.

## Decisión

Se implementarán motores configurables para:

Formularios

Reportes

Permisos

Prompts

Workflows

Dashboards

Reglas

Notificaciones

## Consecuencias

Mayor complejidad inicial.

Muchísima mayor escalabilidad.

Mayor reutilización.

Menor costo de mantenimiento.

Capacidad SaaS.
